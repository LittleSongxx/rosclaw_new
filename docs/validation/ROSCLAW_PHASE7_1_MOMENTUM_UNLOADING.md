# ROSClaw Phase 7.1：G1 主动卸力、高位目标与自进化闭环

## 结论

本轮没有用“把机器人站死”的方式掩盖晃动，而是让 G1 在击球前形成更合适的全身动量，并在击球后保留短步恢复和小脑站姿阻尼。相同 80 N 扰动、相同 MuJoCo Body、相同球和地面参数下，新候选相对 Phase 7.1 父策略获得：

| 指标 | 父策略 | 新候选 | 改善 |
|---|---:|---:|---:|
| 击球后骨盆累计路径 | 3.848 m | 1.865 m | 51.5% |
| 击球后最终净漂移 | 1.984 m | 0.504 m | 74.6% |
| 击球后最大偏移 | 2.083 m | 0.622 m | 70.2% |
| 尾段晃动指数 | 0.281 | 0.123 | 56.1% |
| 稳定时间 | 5.30 s | 4.26 s | 19.6% |
| 支撑状态切换次数 | 56 | 49 | 12.5% |
| 球速 | 4.93 m/s | 5.60 m/s | 13.6% |

新候选进球、最终双脚支撑、不摔倒、无关节/力矩越限，并通过逐轨迹严格重放。晋级结论是 `SIM_CHAMPION`，能力上限仍为 `SIM_ONLY`。

高位射门目标从原来的 `z=0.20 m` 提升到 `z=0.55 m`，同时把挑战误差门收紧到 `<=0.30 m`。最终误差为 `0.258 m`，球速为 `8.21 m/s`，严格重放通过。

## 为什么旧动作会“站在那里晃”

旧动作并非真的原地站立。80 N 案例在触球后先向一侧移动，随后参考动作又驱动骨盆反向走很长一段：最终累计路径约 3.85 m，净漂移约 1.98 m。晚期站姿阻尼能让它最终不倒，却来不及消除前面已经形成的反向动量，所以视频上表现为长距离摇晃和碎步。

尝试把 RoboNaldo 的 29 关节行走网络直接接到射门末端时，候选虽然短时减少位移，但全部触发关节越限或失稳。原因是射门末态不在行走策略的训练状态分布内。该路径已按安全门淘汰，没有进入产品默认路径。

最终可行方案是：

1. 冻结 RoboNaldo 射门 prior 和 ROSClaw 安全核；
2. 只搜索有物理含义、受边界约束的高层参数；
3. 用 `stance_offset_y=-0.08` 改善支撑侧准备；
4. 用 `swing_amplitude=1.125` 调整击球腿动量，使原有恢复步更容易把力卸掉；
5. 保留接触与落脚门控的小脑站姿阻尼；
6. 以路径、漂移、最大偏移、晃动、稳定时间和支撑切换共同决定是否晋级。

通俗地说：旧动作像大力踢完以后身体已经冲出去，再靠腰腿硬撑；新动作是在出脚前就把支撑位置和摆腿力度配好，踢完允许迈一个较短的恢复步，把冲量传到地面，再回到双脚稳定支撑。因此它仍然“会动”，但不是站着反复晃，也不是无目的地走远。

## ROSClaw 新增的闭环

```text
MuJoCo 轨迹
  -> 接触后运动与稳定指标
  -> 父/候选严格重放 A/B
  -> 进球与不可变安全门
  -> 主动卸力多指标晋级门
  -> SIM_CHAMPION
  -> 精确动力学域使用候选
  -> 域外自动回退父策略
```

主要实现：

- `g1_recovery_quality.py`
  - 新增击球后骨盆累计路径、净漂移、最大偏移、支撑切换和单脚支撑时长；
  - 新增主动卸力晋级门，禁止只优化一个漂亮指标。
- `g1_recovery_evolution.py`
  - 将候选、父策略、Body、射门 prior、工况和严格重放证据内容寻址绑定；
  - 只允许完整通过门控的候选获得 `SIM_CHAMPION`；
  - 精确工况外确定性回退父策略，避免持续学习造成灾难性遗忘。
- `g1_hat_trick.py`
  - 第三球使用数据晋级后的主动卸力候选；
  - 第一球升级为 `0.55 m` 高位目标和更严格误差门；
  - Hat Trick v3 报告同时保存父策略轨迹、候选轨迹、晋级比较和路由回执。
- `g1_hat_trick_video.py`
  - 第三球加入父策略/新候选同屏对比；
  - 直接显示路径、漂移和晃动降幅；
  - 第一球显示高位目标高度。

## Stability–Plasticity 如何处理

本轮没有让新候选覆盖所有动力学域。额外探测表明，低摩擦或低回弹环境仍可能让父/候选中的一方失稳。因此路由器把候选绑定到已验证的 `scenario_commitment`：

- 工况完全匹配且晋级通过：使用新候选；
- 工况不匹配：使用保留的父策略；
- 候选未通过任何一个门：使用父策略；
- 不修改硬力矩限制、关节限制、Evidence 语义或硬件许可。

这对应“可塑性”学习新卸力动作，同时用父策略与精确路由保持“稳定性”。它是受约束的自进化，不是无边界在线改权重。

## 限制与下一步

- 当前结论仅是 MuJoCo SIM 证据，不代表真实 G1；
- 新候选按精确工况路由，尚不能声称跨摩擦、球质量和回弹系数普遍更优；
- 本轮使用有界参数自进化，没有宣称在线强化学习权重持续更新；
- 下一步应训练射门末态到 locomotion policy 状态分布的安全过渡策略，并在随机扰动方向/时刻、多摩擦与隐藏种子上通过门控后，才扩大候选适用域。
