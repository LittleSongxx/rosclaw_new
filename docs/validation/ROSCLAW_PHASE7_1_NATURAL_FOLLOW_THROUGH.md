# ROSClaw Phase 7.1：G1 自然随挥与抽搐抑制闭环

## 结论

本轮把用户看到的“踢完球后身体抽搐”拆成了两个可独立验证的问题：

1. 真实 MuJoCo 轨迹中的腰部、手臂和全身关节 jerk；
2. 50 Hz 证据轨迹以 30 fps 慢放时，最近帧采样产生的重复帧和跳帧伪影。

两者都已优化，但视频平滑只属于可视化，不能反向充当运控证据。最终三球报告通过，三球均进球、无摔倒、无关节或力矩越限，并通过逐轨迹严格重放。

## 真实动作改善

在相同 Body、相同射门参数、相同 80 N 扰动和相同反馈控制下，新候选只在“已触球且踢球脚重新落地”后，对腰部和双臂启用因果一阶协调滤波；腿部落脚和主动卸力控制不被滤波。新候选与保留的 v5 控制器 A/B 结果如下：

| 指标 | v5 保留控制 | 自然随挥候选 | 变化 |
|---|---:|---:|---:|
| 全身关节加速度 RMS | 18.951 rad/s² | 18.678 rad/s² | -1.4% |
| 全身关节 jerk RMS | 742.967 rad/s³ | 729.002 rad/s³ | -1.9% |
| 腰部 jerk RMS | 684.002 rad/s³ | 661.390 rad/s³ | -3.3% |
| 手臂 jerk RMS | 397.609 rad/s³ | 366.260 rad/s³ | -7.9% |
| 尾段全身 jerk RMS | 1.215 rad/s³ | 1.029 rad/s³ | -15.4% |
| 尾段晃动指数 | 0.12326 | 0.12166 | -1.3% |
| 击球后骨盆路径 | 1.8645 m | 1.8787 m | +0.8% |
| 击球后净位移 | 0.5037 m | 0.5220 m | +3.6% |
| 稳定时间 | 4.26 s | 4.30 s | +0.04 s |
| 支撑状态切换 | 49 | 49 | 不变 |

jerk 从记录到的物理关节速度求导得到，评估从触球后 1 秒开始，因此球脚冲击不会支配自然度分数。候选必须同时满足进球、安全、严格重放、全身/腰/手臂/尾段 jerk 降幅，以及骨盆路径、位移、稳定时间和支撑切换的回归上限；任一门失败都会回退。

这不是把动作“磨得越软越好”。全身低通实验会引入落脚滞后，部分组合把尾段 jerk 放大约 10 倍，已淘汰。自然控制也不能跨工况盲目复用：把它用于移动球第一脚时，恢复指标退化，完整报告按失败处理。因此最终路由只在验证通过的 80 N 恢复工况使用新候选，高位定点球和移动球保留原稳定控制。这是本轮 Stability–Plasticity 防护的具体落地。

## 主动卸力能力没有被牺牲

自然随挥候选仍与原 Phase 7.1 动量父策略进行公平比较；父策略使用原保留控制器，并保持成功、不摔倒。候选获得：

- 击球后骨盆路径减少 51.2%；
- 最终漂移减少 73.7%；
- 最大偏移减少 70.2%；
- 尾段晃动减少 56.7%；
- 稳定时间减少 18.9%；
- 支撑切换减少 12.5%。

自然度提升因此不是通过弱化射门、破坏父策略或隐藏跌倒换来的。80 N 球速仍为 5.60 m/s，误差为 0.135 m；高位 `z=0.55 m` 球速为 8.21 m/s、误差为 0.258 m；移动球第一脚球速为 6.22 m/s。

## 视频抽搐伪影修复

旧渲染器用 `searchsorted` 直接选最近的 50 Hz 轨迹帧。触球附近以 `0.45×` 慢放时，相邻视频帧只前进约 0.015 秒，小于轨迹的 0.020 秒步长，所以会周期性重复同一姿态，再突然跳到下一姿态。即使物理运动连续，观看时也会像抽动。

新渲染器在相邻证据帧之间执行：

- 骨盆、关节和球位置线性插值；
- 骨盆和球姿态使用最短弧四元数 SLERP；
- 相机跟踪使用插值后的骨盆位置；
- 原始轨迹哈希、任务结果和晋级判断保持不变。

新版第三球用同屏方式展示 v5 未平滑上身与 v6 协调随挥。视频清单明确标记 `visualization_only=true`，插值不会生成或修改任务证据。

## ROSClaw 新增闭环

```text
物理关节速度与接触轨迹
  -> 触球后 1 秒自然度窗口
  -> 全身 / 腿 / 腰 / 手臂 / 尾段 jerk
  -> 相同射门、相同工况父/候选严格重放
  -> 进球 + 安全 + 稳定性不可回归门
  -> 仅精确 80 N 恢复域启用候选
  -> 其它工况保留稳定控制器

已通过的证据轨迹
  -> 线性位置插值 + 四元数 SLERP
  -> 30 fps 慢放视频
  -> visualization only，不回写评估
```

主要代码：

- `g1_cerebellar_recovery.py`：接触和落脚双门控的选择性上身协调、激活/残差回执；
- `g1_recovery_quality.py`：物理关节加速度、分组 jerk、尾段 jerk 与自然度晋级门；
- `g1_hat_trick.py`：同参数自然度父/候选 A/B、严格重放、工况限定和失败即回退；
- `g1_hat_trick_video.py`：证据下游插值、v5/v6 同屏和自然度指标标签；
- `unitree_mujoco_backend.py`：平滑激活状态与目标残差进入轨迹。

## 能力边界

- 所有结论仍是 MuJoCo `SIM_ONLY`，不能等同于真实 G1；
- “更像球星”目前指更连贯的全身随挥和更少的非必要 jerk，不代表已学会某位球星的动作风格；
- 腿部 jerk 只下降 0.7%，说明下一阶段仍需专门训练“射门末态到行走/站立策略”的安全过渡策略；
- 候选只绑定已验证的 80 N 工况，扩展到随机扰动方向、摩擦、球质量和隐藏种子前必须重新通过同一套闭环门。
